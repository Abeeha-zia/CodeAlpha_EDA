# CodeAlpha Exploratory Data Analysis (EDA)

## Project Overview
This project performs exploratory data analysis on a book dataset to understand its structure, identify patterns, and summarize its main characteristics.

## Objectives
- Examine dataset dimensions and data types.
- Check missing values and duplicate records.
- Calculate descriptive statistics.
- Analyze book prices and ratings.
- Explore price distributions and potential outliers.
- Present findings using charts.

## Tools and Technologies
- Python
- Pandas
- Matplotlib

## Files Included
- `eda_analysis.py` — EDA source code.
- `books_dataset_5_pages.csv` — Dataset used for analysis.
- `price_category_eda.png`
- `price_distribution.png`
- `price_outliers.png`
- `price_rating_relationship.png`
- `rating_distribution.png`
- Task 2 PDF report.

## How to Run
Install the required libraries:

`pip install pandas matplotlib`

Run the script:

`python eda_analysis.py`

Ensure the CSV dataset is available at the path specified in the script.
